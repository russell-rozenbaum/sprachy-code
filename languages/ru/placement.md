# Russian 🇷🇺 placement test (10 questions, ~2 min)

Show all 10 in one message and ask the user to answer by number, e.g. `1a 2 ya ne znayu 3 …`. **Translit answers count fully** (*fayle / faile / fajle* all = *файле*); ignore ё/е, stress, and soft signs. "?" or "skip" = don't know; that's fine, **no guessing encouraged**. Say it takes ~2 minutes and can be skipped (then default `level: A1`).

Questions go A1 → C1, so a beginner can stop early.

1. **(A1)** "My name is Sam" → Меня ___ Сэм. (a) зовут (b) имя (c) называю
2. **(A1)** Translate: "I don't know."
3. **(A1)** Translate: "Where is the file?"
4. **(A2)** "The bug is in the file" → Баг в ___ (файл).
5. **(A2)** "I see the error" → Я вижу ___ (ошибка).
6. **(A2)** "The program doesn't start" → Программа не ___ (a) запускает (b) запускается
7. **(B1)** Aspect: "Я уже ___ задачу, можно проверять." (a) делал (b) сделал
8. **(B1)** "Every day I go to the office (on foot)" → Каждый день я ___ в офис. (a) иду (b) хожу
9. **(B2)** Case: "Я работаю с ___ (новая база данных)."
10. **(C1)** Rewrite this more formally, in one sentence: "Мы это сделали, потому что начальник так хотел."

## Answer key
1a · 2 "Я не знаю" (*ya ne znayu*) · 3 "Где файл?" (*gde fayl?*; extra *есть* = wrong) · 4 файл**е** · 5 ошибк**у** · 6b · 7b · 8b · 9 нов**ой** баз**ой** данных (both endings needed) · 10 open answer. Look for passive or nominal style, e.g. "Это было сделано по указанию руководства." Give it 0, ½, or 1 point.

## Scoring → level
| Correct | Level |
|---|---|
| 0 | A0 (total beginner: start with micro-lessons in English) |
| 1–2 | A1 |
| 3–4 | A2 |
| 5–7 | B1 |
| 8–9 | B2 |
| 10 | C1 |

If the user got items 5–7 right but scored lower overall, round up. Case, -ся, and aspect (items 5–7, 9) are the best predictors of level; 8 is a weaker predictor because motion verbs are drilled early but rarely used in tech chat (see method.md §Readiness).
