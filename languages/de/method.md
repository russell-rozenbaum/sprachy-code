# German 🇩🇪: method notes

## 1. Target variant & register
- **Correct toward:** Standard German. In tech chat, informal *du* is the norm (flag *du*/*Sie* only in formal external text).
- **Tolerate without comment:**
  - ae/oe/ue/ss instead of umlauts
  - lowercase nouns
  - spoken "weil + V2" at A-levels
  - English tech nouns
  - German-inflected tech verbs (*gepusht, committet, deployt*)

## 2. Error priorities for English speakers
1. `v2`: *Dann ich habe* → *Dann **habe ich*** (A1+)
2. `verb-final`: *weil es ist kaputt* → *weil es kaputt **ist*** (A2+)
3. `gender`: *das Funktion* → ***die** Funktion*. Suffix tips: -ung/-heit/-keit → die; -chen → das. Be lenient with loanwords (der/das Commit). (A1+)
4. `sep-verb`: *Ich anrufe dich* → *Ich **rufe** dich **an***; participle goes last: *Ich habe **gefixt** das* → *Ich habe das **gefixt*** (A2+)
5. `perfekt-aux`: *ich habe gegangen* → *ich **bin** gegangen* (A2+)
6. `case-acc`: *für der Test* → *für **den** Test* (B1+)
7. `case-dat`: *mit das Tool* → *mit **dem** Tool*; *hilf mich* → *hilf **mir*** (B1+)
8. `adj-ending`: *ein gut Idee* → *eine gut**e** Idee* (B1+, low priority)
9. `false-friend`: see §4
10. `vocab`: a missing or wrong word

## 3. Readiness / acquisition order
- **Word order** develops in this sequence: SVO → adverb-fronting → verb separation → inversion (V2) → verb-final. Correct only the learner's current or next stage (Pienemann 1998, Processability Theory).
- **Case** comes late: nominative → accusative → dative. Ignore case at A-levels (Diehl et al. 2000, DiGS study).
- **Gender** is item-learned. Give the right form, not a rule (Yang & Lyster 2010).

## 4. False friends & tech-talk
| Looks like | Actually means | Say instead |
|---|---|---|
| aktuell | current | (for "actual": tatsächlich) |
| eventuell | maybe | (for "eventually": schließlich) |
| also | so / therefore | (for "also": auch) |
| bekommen | get / receive | (for "become": werden) |
| Chef | boss | (for "chef": Koch) |
| realisieren | implement (not "realize") | (for "realize": merken) |
| Sinn machen | anglicism | Sinn ergeben |
| sensibel | sensitive | (for "sensible": vernünftig) |

## 5. Micro-lesson chunks (A0–A2)
1. Kannst du …? = Can you …?
2. Ich brauche … = I need …
3. Es funktioniert nicht. = It doesn't work.
4. Was ist das Problem? = What's the problem?
5. Bitte / Danke! = Please / Thanks!
6. Wie mache ich …? = How do I …?
7. Warum …? = Why …?
8. Ich möchte … = I would like …
9. Noch einmal, bitte. = Once more, please.
10. Das ist gut / falsch. = That's good / wrong.
