# German 🇩🇪 placement test (10 questions, ~2 min)

Show all 10 in one message and ask the user to answer by number, e.g. `1b 2a 3 ich bin …`. "?" or "skip" = don't know; that's fine, **no guessing encouraged**. Say it takes ~2 minutes and can be skipped (then default `level: A1`).

Questions go A1 → C1, so a beginner can stop early.

1. **(A1)** "Hello, my name is Sam" → Hallo, ___ heiße Sam. (a) ich (b) mich (c) mein
2. **(A1)** der, die, or das? ___ Haus
3. **(A1)** Translate: "I need coffee."
4. **(A2)** Fix the word order: "Morgen ich gehe ins Büro."
5. **(A2)** Perfekt: "Ich ___ gestern nach Berlin gefahren." (a) habe (b) bin
6. **(B1)** Finish the sentence: "Ich lerne Deutsch, weil ich in München ___ ___." (arbeiten, will)
7. **(B1)** Separable verb: "(anrufen) Ich ___ dich morgen ___."
8. **(B1)** Case: "Ich fahre mit ___ Auto." (a) das (b) dem (c) den
9. **(B2)** Adjective ending: "Das ist ein gut___ Idee."
10. **(C1)** Rewrite this more formally, in one sentence: "Wir haben das gemacht, weil der Chef es wollte."

## Answer key
1a · 2 das · 3 "Ich brauche Kaffee." · 4 "Morgen gehe ich ins Büro." · 5b · 6 "arbeiten will" · 7 rufe … an · 8b · 9 gut**e** · 10 open answer. Look for nominal style or a passive, e.g. "Dies geschah auf Wunsch der Leitung." Give it 0, ½, or 1 point.

## Scoring → level
| Correct | Level |
|---|---|
| 0 | A0 (total beginner: start with micro-lessons in English) |
| 1–2 | A1 |
| 3–4 | A2 |
| 5–7 | B1 |
| 8–9 | B2 |
| 10 | C1 |

If the user got all of the B1 items (6–8) right but scored lower overall, round up. Items 6–8 test word order and case, which are the best predictors of level (see method.md §Readiness).
